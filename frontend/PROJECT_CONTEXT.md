# Frontend Project Context

## 프로젝트
공학관 학과별 기자재 대여 시스템

## 담당
Frontend 개발

## 기술 스택
- React
- Vite
- React Router

## 현재 구조

frontend/src

pages/
- Home.jsx
- EquipmentDetail.jsx
- Rental.jsx
- MyPage.jsx

components/
- 공통 컴포넌트 위치

## 사용자 흐름

학생
→ 학과 선택
→ 기자재 목록 조회
→ 기자재 상세 확인
→ 대여 신청
→ 마이페이지 확인

## 구현 목표

1. 페이지별 UI 구현
2. React Router 기반 페이지 이동
3. 컴포넌트 재사용 구조
4. Backend API 연결 고려

## 개발 규칙

- 기존 폴더 구조를 임의로 변경하지 않는다.
- 코드 작성 전 작업 계획을 먼저 설명한다.
- 페이지와 재사용 컴포넌트를 분리한다.
