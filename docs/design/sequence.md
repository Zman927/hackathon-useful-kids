# 시퀀스 다이어그램

## 1. 대여 신청 (학생)

```
Student          Frontend            Backend             DB
  │                  │                  │                 │
  │  기자재 선택       │                  │                 │
  ├─────────────────▶│                  │                 │
  │                  │ GET /equipment   │                 │
  │                  ├─────────────────▶│                 │
  │                  │                  │ SELECT equipment│
  │                  │                  ├────────────────▶│
  │                  │                  │◀────────────────┤
  │                  │◀─────────────────┤                 │
  │  신청 폼 제출      │                  │                 │
  ├─────────────────▶│                  │                 │
  │                  │ POST /rentals    │                 │
  │                  ├─────────────────▶│                 │
  │                  │                  │ equipment 존재 확인│
  │                  │                  ├────────────────▶│
  │                  │                  │ INSERT rental    │
  │                  │                  │ (status=신청됨)   │
  │                  │                  ├────────────────▶│
  │                  │◀─────────────────┤                 │
  │◀─────────────────┤ 신청 완료 표시     │                 │
```

## 2. 승인 처리 (조교)

```
Assistant        Frontend            Backend             DB
  │                  │                  │                 │
  │  대시보드 진입     │                  │                 │
  ├─────────────────▶│                  │                 │
  │                  │ GET /rentals?status=신청됨          │
  │                  ├─────────────────▶│                 │
  │                  │                  ├────────────────▶│
  │                  │◀─────────────────┤                 │
  │  승인 클릭         │                  │                 │
  ├─────────────────▶│                  │                 │
  │                  │ PATCH /rentals/{id}/approve         │
  │                  ├─────────────────▶│                 │
  │                  │                  │ status=PENDING 확인│
  │                  │                  │ available_quantity│
  │                  │                  │ -1, status=대여중  │
  │                  │                  ├────────────────▶│
  │                  │◀─────────────────┤                 │
  │◀─────────────────┤ 목록 갱신          │                 │
```
