# PRD — 제품 요구사항 정의서

> 실제 구현 기준으로 갱신.

## 배경 / 문제 정의

공학관 기자재 대여는 현재 학생이 학과 사무실을 직접 찾아가 재고를 물어보고, 대여 기록은 수기 장부로 남긴다.

- 학생 입장: 어떤 기자재가 있는지, 지금 빌릴 수 있는지 미리 알 방법이 없다.
- 조교 입장: 수기 장부와 별도 파일(엑셀 등)로 이중 관리해야 한다.

## 타깃 사용자

- **학생**: 프로젝트/과제에 필요한 기자재를 빌리려는 재학생
- **조교**: 학과 기자재를 관리하고 대여 신청을 승인·반려·반납 처리하는 담당자

## 핵심 가치 제안

기자재 재고 조회부터 신청, 승인, 반납까지 한 곳에서 처리한다. 수기 장부와 이중 관리를 없앤다.

## 목표 / 성공 기준

- 학생이 학과별 기자재 재고를 실시간으로 조회할 수 있다
- 학생이 대여를 신청하고 조교가 승인/반려할 수 있다
- 조교가 반납 처리를 하면 재고가 자동으로 갱신된다
