# 요구사항 정의서 (기능 명세)

> 실제 구현 기준으로 갱신.

## 화면 목록

| 화면 | 경로 | 사용자 |
|---|---|---|
| 로그인 | `/login` | 학생, 조교 |
| 기자재 목록 (학과 선택) | `/` | 학생, 조교 |
| 기자재 상세 | `/equipment/:id` | 학생, 조교 |
| 대여 신청 | `/rental` | 학생, 조교 |
| 마이페이지 (본인 대여 현황) | `/mypage` | 학생, 조교 |
| 조교 대시보드 | `/admin` | 조교 |

## 기능 상세

### 공통 (로그인 필요)

- 학번(또는 조교 계정)과 비밀번호로 로그인하면 JWT를 발급받는다.
- 역할(학생/조교)에 따라 접근 가능한 화면·API가 다르다.
- 로그인한 사용자는 역할과 무관하게 본인 명의로 대여를 신청·조회·취소할 수 있다 (조교도 자기 학과 또는 타 학과 기자재를 빌릴 수 있음).

### 학생 · 조교 공통 (대여자 입장)

- 학과를 선택해 기자재 목록을 조회한다 (재고 수량, 사진 포함)
- 기자재 상세 정보를 확인한다
- 대여를 신청한다 (기자재, 대여 기간, 수량, 사유) — 신청자 정보(이름/학번/학과)는 로그인 세션에서 자동으로 채워진다
- 본인의 대여 신청 현황을 조회한다 (`GET /rentals`)
- 심사 대기(`PENDING`) 중인 본인 신청을 취소한다

### 조교 (관리자 입장)

- 본인 학과의 대여 신청 목록을 확인한다 (`GET /rentals/all`)
- 신청을 승인하거나 반려한다
- 대여중인 기자재의 반납을 처리한다 — 처리 시 재고가 자동으로 복구된다
- 본인 학과 기자재를 등록/수정한다 (사진 업로드 포함)

## 인증/권한 요약

| 행위 | 필요 권한 |
|---|---|
| 기자재 조회, 학과 목록 조회 | 없음 (비로그인 가능) |
| 대여 신청/조회/취소 | 로그인 (학생/조교 무관) |
| 기자재 등록/수정 | 조교, 본인 학과만 |
| 대여 승인/반려/반납/전체 조회 | 조교, 본인 학과만 |

## 현재 구현 범위

| 구분 | 내용 |
|---|---|
| 구현됨 | 로그인(JWT), 기자재 조회/등록/수정(사진 포함), 대여 신청/승인/반려/반납/취소, 학과별 조회, 마이페이지 |
| 구현 안 됨 (문서만, 미구현) | 예약 캘린더/기간 충돌 방지, 학생증 인증 연동, 회원가입(계정은 시드 데이터로만 존재) |

세부 API 계약은 [rest-api.md](../api/rest-api.md), 데이터 모델은 [erd.md](../design/erd.md) 참고.
