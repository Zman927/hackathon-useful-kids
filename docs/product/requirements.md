# 요구사항 정의서 (기능 명세)

> 개발 완료 후 실제 구현 기준으로 갱신.

## 화면 목록

| 화면 | 경로 | 사용자 |
|---|---|---|
| 기자재 목록 | `/` | 학생 |
| 기자재 상세 | `/equipment/:id` | 학생 |
| 대여 신청 | `/rental` | 학생 |
| 마이페이지 (Tier 1) | `/mypage` | 학생 |
| 조교 대시보드 | `/admin` | 조교 |

## 기능 상세

### 학생

- 학과를 선택해 기자재 목록을 조회한다 (재고 수량 포함)
- 기자재 상세 정보를 확인한다
- 대여를 신청한다 (이름, 학번, 연락처, 사유)
- (Tier 1) 본인의 대여 신청 현황을 조회한다

### 조교

- 대기 중인 대여 신청 목록을 확인한다
- 신청을 승인하거나 반려한다
- 대여중인 기자재의 반납을 처리한다

## MVP (Tier 0) / 확장 범위 (Tier 1, 2)

| Tier | 내용 |
|---|---|
| Tier 0 (필수) | 위 "학생"·"조교" 항목 중 마이페이지 제외 전부 |
| Tier 1 (여유 시) | 마이페이지(본인 대여 현황) |
| Tier 2 (문서만, 미구현) | 예약 캘린더/충돌 방지, 학생증 인증 연동 |

세부 API 계약은 [rest-api.md](../api/rest-api.md), 데이터 모델은 [erd.md](../design/erd.md) 참고.
