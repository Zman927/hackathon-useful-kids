## 프로젝트

공학관 기자재 대여를 디지털화하는 플랫폼. 학생은 학과별 기자재 재고를 조회하고 대여를 신청하며, 조교는 대시보드에서 신청을 승인·반려하고 반납을 처리한다. 기존의 수기 장부와 조교별 파일 관리를 대체하는 것이 목표다.

## 스택

- **프론트엔드**: React
- **백엔드**: FastAPI
- **DB**: PostgreSQL

## 브랜치 전략

- `main` — 통합 브랜치. 시연·제출에 쓰이는 상태.
- `frontend` — 프론트엔드 작업 브랜치. `frontend/` 폴더만 다룬다.
- `backend` — 백엔드 작업 브랜치. `backend/` 폴더만 다룬다.

각자 브랜치에서 작업하고, 기능이 완성되면 `main`으로 머지한다.

## 폴더 구조

```
frontend/   React 앱
backend/    FastAPI 앱
```
